+-------------------------------------------------------------------------------------------------------------------------------------------------+
| **HISTORIA DE USUARIO**                                                                                                                         |
+---------------+-------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Código:**   | HU-19                         | **Nombre:**                   | Gestionar tipos de error                                        |
+---------------+-------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Complejidad:**                              | Baja                                                                                            |
+-----------------------------------------------+-------------------------------------------------------------------------------------------------+
| **HU Relacionada:**                           | HU-12                                                                                           |
+-----------------------------------------------+-------------------------------------------------------------------------------------------------+
| **Módulo:**                                   | Administración de Catálogos                                                                     |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Descripción:**                              | **Yo como**                   | Coordinador de proyectos                                        |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Requiero**                  | administrar el catálogo de tipos de error mediante operaciones  |
|                                               |                               | de registro, consulta, actualización e inhabilitación lógica.   |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Para**                      | mantener actualizado el listado de tipos de error utilizados    |
|                                               |                               | durante el registro de incidencias del sistema.                 |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Requerimiento:**                            | \- El sistema debe permitir registrar nuevos tipos de error.                                    |
|                                               |                                                                                                 |
|                                               | \- El sistema debe permitir consultar los tipos de error registrados.                           |
|                                               |                                                                                                 |
|                                               | \- El sistema debe permitir modificar la información de un tipo de error existente.             |
|                                               |                                                                                                 |
|                                               | \- El sistema debe permitir realizar la inhabilitación lógica de un tipo de error.              |
|                                               |                                                                                                 |
|                                               | \- El sistema debe impedir registrar tipos de error duplicados.                                 |
|                                               |                                                                                                 |
|                                               | \- El sistema debe impedir inhabilitar tipos de error que se encuentren asociados a registros   |
|                                               | de errores.                                                                                     |
|                                               |                                                                                                 |
|                                               | \- El sistema debe mostrar únicamente los tipos de error activos durante el registro de         |
|                                               | errores.                                                                                        |
|                                               |                                                                                                 |
|                                               | \- El sistema debe registrar la trazabilidad de las operaciones realizadas sobre el catálogo.   |
|                                               |                                                                                                 |
|                                               | \- El sistema debe informar el resultado de cada operación realizada.                           |
+-----------------------------------------------+-------------------------------------------------------------------------------------------------+
| **CRITERIOS DE ACEPTACIÓN**                                                                                                                     |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 01**                              | **Dado:**                     | que el coordinador accede al módulo de tipos de error           |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | registra un nuevo tipo de error con información válida          |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema almacena el registro y lo incorpora al catálogo      |
|                                               |                               | disponible                                                      |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 02**                              | **Dado:**                     | que el coordinador consulta el catálogo de tipos de error       |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | existen registros disponibles                                   |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema muestra el listado con su información y estado       |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 03**                              | **Dado:**                     | que el coordinador selecciona un tipo de error existente        |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | actualiza su información                                        |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema guarda los cambios correctamente                     |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 04**                              | **Dado:**                     | que el coordinador intenta registrar un tipo de error ya        |
|                                               |                               | existente                                                       |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | el nombre coincide con otro registro activo                     |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema impide el registro e informa la duplicidad           |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 05**                              | **Dado:**                     | que el coordinador selecciona un tipo de error sin registros    |
|                                               |                               | asociados                                                       |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | solicita su inhabilitación                                      |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema cambia su estado a inactivo conservando el historial |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 06**                              | **Dado:**                     | que un tipo de error posee registros asociados                  |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | el coordinador intenta inhabilitarlo                            |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema bloquea la operación e informa que existen registros |
|                                               |                               | relacionados                                                    |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 07**                              | **Dado:**                     | que un desarrollador registra un error                          |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | consulta los tipos de error disponibles                         |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema muestra únicamente los tipos de error activos        |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 08**                              | **Dado:**                     | que el coordinador realiza una operación sobre un tipo de error |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | la operación finaliza correctamente                             |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema registra automáticamente la trazabilidad             |
|                                               |                               | correspondiente                                                 |
