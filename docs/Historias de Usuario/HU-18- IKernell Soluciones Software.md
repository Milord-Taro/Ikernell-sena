+-------------------------------------------------------------------------------------------------------------------------------------------------+
| **HISTORIA DE USUARIO**                                                                                                                         |
+---------------+-------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Código:**   | HU-18                         | **Nombre:**                   | Consultar trazabilidad del sistema                              |
+---------------+-------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Complejidad:**                              | Media                                                                                           |
+-----------------------------------------------+-------------------------------------------------------------------------------------------------+
| **HU Relacionada:**                           | HU-05, HU-07, HU-08, HU-09, HU-12, HU-13, HU-14, HU-15, HU-16, HU-17                            |
+-----------------------------------------------+-------------------------------------------------------------------------------------------------+
| **Módulo:**                                   | Auditoría y Trazabilidad                                                                        |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Descripción:**                              | **Yo como**                   | Coordinador de proyectos                                        |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Requiero**                  | consultar el historial de operaciones realizadas sobre la       |
|                                               |                               | información del sistema.                                        |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Para**                      | auditar los cambios efectuados por los usuarios y facilitar el  |
|                                               |                               | seguimiento de las actividades administrativas.                 |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Requerimiento:**                            | \- El sistema debe registrar automáticamente las operaciones realizadas sobre la información    |
|                                               | administrada.                                                                                   |
|                                               |                                                                                                 |
|                                               | \- El sistema debe permitir consultar el historial de trazabilidad.                             |
|                                               |                                                                                                 |
|                                               | \- El sistema debe permitir filtrar la información por usuario.                                 |
|                                               |                                                                                                 |
|                                               | \- El sistema debe permitir filtrar la información por módulo.                                  |
|                                               |                                                                                                 |
|                                               | \- El sistema debe permitir filtrar la información por tipo de operación.                       |
|                                               |                                                                                                 |
|                                               | \- El sistema debe permitir filtrar la información por rango de fechas.                         |
|                                               |                                                                                                 |
|                                               | \- El sistema debe mostrar el detalle de cada operación registrada.                             |
|                                               |                                                                                                 |
|                                               | \- El sistema debe conservar el historial aun cuando el registro original sea inhabilitado.     |
|                                               |                                                                                                 |
|                                               | \- El sistema debe restringir la consulta de la trazabilidad únicamente al Coordinador.         |
|                                               |                                                                                                 |
|                                               | \- El sistema debe informar cuando la consulta no genere resultados.                            |
+-----------------------------------------------+-------------------------------------------------------------------------------------------------+
| **CRITERIOS DE ACEPTACIÓN**                                                                                                                     |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 01**                              | **Dado:**                     | que el coordinador accede al módulo de trazabilidad             |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | consulta el historial del sistema                               |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema muestra las operaciones registradas ordenadas        |
|                                               |                               | cronológicamente                                                |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 02**                              | **Dado:**                     | que existen registros de trazabilidad                           |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | el coordinador aplica filtros de búsqueda                       |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema muestra únicamente los registros que cumplen los     |
|                                               |                               | criterios seleccionados                                         |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 03**                              | **Dado:**                     | que el coordinador selecciona un registro del historial         |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | consulta el detalle de la operación                             |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema muestra el usuario responsable, la fecha, la         |
|                                               |                               | operación realizada y la información afectada                   |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 04**                              | **Dado:**                     | que una operación corresponde a un registro actualmente         |
|                                               |                               | inhabilitado                                                    |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | el coordinador consulta el historial                            |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema conserva y muestra la información histórica          |
|                                               |                               | registrada                                                      |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 05**                              | **Dado:**                     | que una consulta no encuentra registros                         |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | el coordinador ejecuta la búsqueda                              |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema informa que no existen resultados para los filtros   |
|                                               |                               | seleccionados                                                   |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 06**                              | **Dado:**                     | que un usuario diferente al Coordinador intenta acceder al      |
|                                               |                               | módulo                                                          |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | solicita visualizar la trazabilidad                             |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema deniega el acceso e informa que no posee permisos    |
|                                               |                               | suficientes                                                     |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 07**                              | **Dado:**                     | que el coordinador consulta un registro de trazabilidad         |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | la operación corresponde a una creación, modificación o         |
|                                               |                               | inhabilitación                                                  |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema identifica claramente el tipo de operación realizada |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 08**                              | **Dado:**                     | que el coordinador consulta el historial de un módulo           |
|                                               |                               | específico                                                      |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | selecciona el módulo correspondiente                            |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema muestra únicamente las operaciones registradas para  |
|                                               |                               | dicho módulo                                                    |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
