+-----------------------------------------------+-------------------------------------------------------------------------------------------------+
| **HU Relacionada:**                           | HU-05                                                                                           |
+-----------------------------------------------+-------------------------------------------------------------------------------------------------+
| **Módulo:**                                   | Administración de Catálogos                                                                     |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Descripción:**                              | **Yo como**                   | Coordinador de proyectos                                        |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Requiero**                  | administrar el catálogo de profesiones disponibles en el        |
|                                               |                               | sistema mediante operaciones de registro, consulta,             |
|                                               |                               | actualización e inhabilitación lógica.                          |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Para**                      | mantener actualizado el listado de profesiones utilizado        |
|                                               |                               | durante la gestión de los perfiles de los desarrolladores.      |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Requerimiento:**                            | \- El sistema debe permitir registrar nuevas profesiones.                                       |
|                                               |                                                                                                 |
|                                               | \- El sistema debe permitir consultar las profesiones registradas.                              |
|                                               |                                                                                                 |
|                                               | \- El sistema debe permitir modificar la información de una profesión existente.                |
|                                               |                                                                                                 |
|                                               | \- El sistema debe permitir realizar la inhabilitación lógica de una profesión.                 |
|                                               |                                                                                                 |
|                                               | \- El sistema debe impedir registrar profesiones duplicadas.                                    |
|                                               |                                                                                                 |
|                                               | \- El sistema debe impedir eliminar físicamente profesiones que tengan desarrolladores          |
|                                               | asociados.                                                                                      |
|                                               |                                                                                                 |
|                                               | \- El sistema debe mostrar únicamente profesiones activas durante el registro y edición de      |
|                                               | desarrolladores.                                                                                |
|                                               |                                                                                                 |
|                                               | \- El sistema debe registrar la trazabilidad de las operaciones realizadas sobre las            |
|                                               | profesiones.                                                                                    |
|                                               |                                                                                                 |
|                                               | \- El sistema debe informar al usuario el resultado de cada operación realizada.                |
+-----------------------------------------------+-------------------------------------------------------------------------------------------------+
| **CRITERIOS DE ACEPTACIÓN**                                                                                                                     |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 01**                              | **Dado:**                     | que el coordinador accede al módulo de profesiones              |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | registra una nueva profesión con información válida             |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema almacena la profesión y la incorpora al catálogo     |
|                                               |                               | disponible                                                      |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 02**                              | **Dado:**                     | que el coordinador consulta el listado de profesiones           |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | existen profesiones registradas                                 |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema muestra únicamente la información correspondiente a  |
|                                               |                               | cada profesión junto con su estado                              |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 03**                              | **Dado:**                     | que el coordinador selecciona una profesión existente           |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | actualiza su información con datos válidos                      |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema guarda los cambios y actualiza el catálogo           |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 04**                              | **Dado:**                     | que el coordinador intenta registrar una profesión existente    |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | el nombre coincide con otra profesión registrada                |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema impide el registro e informa que la profesión ya     |
|                                               |                               | existe                                                          |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 05**                              | **Dado:**                     | que el coordinador selecciona una profesión activa              |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | solicita su inhabilitación                                      |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema cambia su estado a inactiva sin eliminar el registro |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 06**                              | **Dado:**                     | que una profesión posee desarrolladores asociados               |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | el coordinador intenta eliminarla                               |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema informa que la profesión posee registros asociados y |
|                                               |                               | bloquea la operación cuando corresponda según las reglas de     |
|                                               |                               | negocio                                                         |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 07**                              | **Dado:**                     | que un coordinador registra o modifica un desarrollador         |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | consulta el listado de profesiones disponibles                  |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema muestra únicamente las profesiones activas           |
+-----------------------------------------------+-------------------------------+-----------------------------------------------------------------+
| **Condición 08**                              | **Dado:**                     | que el coordinador realiza una operación sobre una profesión    |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Cuando:**                   | la operación finaliza correctamente                             |
|                                               +-------------------------------+-----------------------------------------------------------------+
|                                               | **Entonces:**                 | el sistema registra automáticamente la trazabilidad de la       |
|                                               |                               | acción realizada                                                |
