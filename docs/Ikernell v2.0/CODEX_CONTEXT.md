# IKernell v2 Overhaul

## Objetivo

Este proyecto se encuentra en un overhaul completo.

NO es un proyecto nuevo.

Debe respetarse el alcance funcional del caso de estudio.

El objetivo es mejorar:

- arquitectura
- dominio
- base de datos
- backend
- frontend
- UX
- documentación

1. Caso de estudio
2. Reglas de negocio
3. Dominio
4. DER
5. SQL
