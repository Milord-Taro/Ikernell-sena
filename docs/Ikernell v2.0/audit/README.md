# Auditoría de Consistencia

Esta carpeta contiene el proceso de auditoría realizado durante el overhaul de IKernell v2.

El objetivo consiste en verificar que todos los artefactos del proyecto representen correctamente el dominio del negocio.

Cada auditoría analiza una entidad desde múltiples perspectivas:

- Caso de Estudio
- Historias de Usuario
- Requerimientos
- Casos de Uso
- Dominio
- DER
- SQL
- Backend
- Frontend
- Documentación

Las inconsistencias identificadas serán corregidas siguiendo el orden definido en la arquitectura del proyecto.
