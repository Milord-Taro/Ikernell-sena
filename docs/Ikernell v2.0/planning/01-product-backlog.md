# IKernell v2 — Product Backlog

> Backlog maestro del proceso de evolución de IKernell Soluciones Software.

---

# Objetivo

Este documento actúa como índice principal del Product Backlog de IKernell v2.

Cada épica representa un área funcional del sistema y dispone de su propia especificación dentro de la carpeta `planning/backlog`.

El propósito de este documento es ofrecer una visión ejecutiva del estado general del proyecto y facilitar el seguimiento del desarrollo.

---

# Flujo de Trabajo
