# Reglas del Overhaul

## Nunca

- Duplicar componentes
- Duplicar estilos
- Duplicar lógica

---

## Siempre

- Reutilizar componentes

- Reutilizar servicios

- Reutilizar DTO

- Actualizar documentación

---

## Frontend

Una vista nueva deberá utilizar:

- Layout común

- Componentes comunes

- Tipografía común

- Espaciado común

- Botones comunes

---

## Backend

Toda nueva lógica deberá implementarse en Service.

No agregar lógica al Controller.

---

## Base de Datos

Toda modificación deberá reflejarse en:

- SQL

- DER

- Diccionario

---

## Documentación

Todo cambio funcional deberá actualizar:

- HU

- RF

- Casos de Uso
