# Product Backlog — IKernell v2

> Especificación funcional de las épicas que conforman el Product Backlog de IKernell.

---

# Objetivo

Esta carpeta contiene la documentación individual de cada épica definida para el proceso de evolución de IKernell v2.

Cada documento describe el alcance funcional de un módulo del sistema, su objetivo, funcionalidades, dependencias e impacto técnico.

# Mantenimiento

Las épicas podrán actualizarse durante el desarrollo del proyecto conforme evolucionen los requerimientos, el dominio del negocio o las observaciones recibidas durante las revisiones.

Toda modificación deberá mantenerse alineada con la arquitectura general definida para IKernell v2.
