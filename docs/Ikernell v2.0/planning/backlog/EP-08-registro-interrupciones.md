# EP-08 — Registro de Interrupciones

---

## Objetivo

Registrar y administrar las interrupciones ocurridas durante el desarrollo de las actividades para facilitar el seguimiento y análisis del proyecto.

---

## Alcance

Incluye:

- Registrar interrupciones.
- Clasificarlas.
- Consultarlas.
- Editarlas.
- Analizar historial.

---

## Actores

- Líder.
- Desarrollador.

---

## Features

- Registrar interrupción.
- Editar registro.
- Eliminar registro.
- Consultar detalle.
- Buscar registros.
- Filtrar registros.

---

## Entidades

- Interrupcion.
- TipoInterrupcion.
- Actividad.

---

## Reglas del negocio

- Toda interrupción deberá estar asociada a una actividad.
- Toda interrupción deberá tener un tipo definido.

---

## Dependencias

- EP-06 Gestión de Actividades.

---
