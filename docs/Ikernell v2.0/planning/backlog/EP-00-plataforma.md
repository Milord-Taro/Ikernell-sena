# EP-00 — Plataforma y Fundamentos

---

## Objetivo

Preparar la infraestructura técnica, arquitectónica y visual necesaria para soportar el proceso de evolución de IKernell hacia la versión 2.

Esta épica reúne todas aquellas actividades que no representan funcionalidades visibles para el usuario final, pero que resultan indispensables para garantizar un desarrollo consistente, mantenible y escalable.

---

## Problema que resuelve

La primera versión de IKernell fue desarrollada como una implementación funcional del caso de estudio.

Durante su construcción se identificaron oportunidades de mejora relacionadas con la organización del código, reutilización de componentes, consistencia visual, estructura de la arquitectura y documentación.

Sin una base sólida, cualquier nueva funcionalidad incrementaría la deuda técnica del proyecto.

---

## Alcance

Esta épica comprende la preparación de la plataforma antes de iniciar el desarrollo funcional.

Incluye la definición de estándares, arquitectura, diseño, documentación y herramientas que servirán como base para las siguientes fases del proyecto.
