# EP-05 — Gestión de Etapas

---

## Objetivo

Administrar las etapas que conforman un proyecto y organizar el avance del trabajo mediante una estructura lógica y secuencial.

---

## Alcance

Incluye:

- Crear etapas.
- Editar etapas.
- Consultar etapas.
- Eliminar etapas.
- Reordenar etapas.
- Consultar actividades asociadas.

---

## Actores

- Coordinador.
- Líder.

---

## Features

- Crear etapa.
- Editar etapa.
- Eliminar etapa.
- Consultar etapa.
- Ordenar etapas.
- Visualizar progreso.

---

## Entidades

- Etapa.
- Proyecto.

---

## Reglas del negocio

- Toda etapa pertenece a un proyecto.
- Una etapa puede contener múltiples actividades.
- El orden de las etapas deberá mantenerse consistente.
