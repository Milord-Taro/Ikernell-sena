# EP-06 — Gestión de Actividades

---

## Objetivo

Administrar las actividades necesarias para ejecutar cada etapa del proyecto, permitiendo su planificación, asignación y seguimiento.

---

## Alcance

Incluye:

- Crear actividades.
- Asignar responsables.
- Cambiar estado.
- Registrar progreso.
- Consultar detalle.

---

## Actores

- Líder.
- Desarrollador.

---

## Features

- Crear actividad.
- Editar actividad.
- Eliminar actividad.
- Asignar desarrollador.
- Cambiar estado.
- Registrar avance.
- Buscar actividades.
- Filtrar actividades.

---

## Entidades

- Actividad.
- Usuario.
- Etapa.

---

## Reglas del negocio

- Toda actividad pertenece a una etapa.
- Una actividad deberá tener un responsable.
- El estado deberá respetar el flujo definido.
